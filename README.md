
# Bagnolesi nel Mondo

This website was made to connect the global Bagnolesi (of ***Bagnoli del Trigno***) diaspora.
## Live Demo

Link to the website: [Bagnolesi nel Mondo](https://bagnolesi-nel-mondo.onrender.com/)




## Features

- Cross platform responsive layout
- Community Piazza (forum)
- User Authentication
- Interactive Forms


## Tech Stack

* **Runtime Environment:** Node.js
* **Backend Framework:** Express.js
* **Architecture:** MVC (Model-View-Controller)
* **Frontend/Templating:** EJS, CSS3
* **Database:** MongoDB


## Installation

Install my-project with npm

```bash
  git clone https://github.com/tcimaglia20/Bagnolesi-nel-Mondo.git
  cd Bagnolesi-nel-Mondo
  npm install
```

To run the development server
```bash
  npm run dev
```
